# Portfólio Profissional

1. Acesse a versão online do projeto aqui: [Portfólio Caíque](https://caiquesf.github.io/portfolio/)

## ➡ Tecnologias Utilizadas

Front-end:

-   HTML5, CSS3 e JavaScript
-   Font Awesome para ícones
-   Google Fonts (Roboto)

## ➡ Objetivo do Projeto

Apresentar meu portfólio profissional como Desenvolvedor Back-end, destacando habilidades, projetos realizados e formas de contato, com design responsivo e interativo.

## ➡ Estrutura do Projeto

```
.
├── index.html                              # Página principal
├── css/
│ └── styles.css                            # Todos os estilos
├── js/
│ └── scripts.js                            # Lógica e animações
├── images/                                 # Recursos visuais
│ ├── minha-foto.png
│ ├── ...
│ └── ...
├── docs/
│ └── Curriculo.pdf                         # Currículo em PDF
└── README.md                               # Documentação
```

## ➡ Funcionalidades Principais

🔹 **Design Responsivo** - Adaptação perfeita para todos os dispositivos
🔹 **Animações Interativas** - Efeitos de digitação e scroll suave
🔹 **Galeria de Projetos** - Apresentação dos principais trabalhos
🔹 **Seção de Contatos** - Acesso rápido aos canais de comunicação
